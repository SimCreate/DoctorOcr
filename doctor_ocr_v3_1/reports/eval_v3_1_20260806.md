# v3_1 (Attention + 증강) — 최종 평가 보고서

> 날짜: 2026-08-06
> 목적: "attention 디코더가 데이터를 충분히 주면 CTC보다 좋다"는 가설의 검증
> 방법: v3_1 best_model (epoch 32, val_loss 1.3886) → beam search(5) → 클린 val 1,116장
> 비교: v3 exp2_clean(CTC) — 동일 val, 동일 지표, 동일 그룹핑

## 최종 결과 (동일 기준 공정 비교)

## 해석

1. **학습 로그(argmax 43.1%)가 실제 디코딩(beam 30.4%)보다 과대평가** — 교육 중 teacher-forcing과 자기생성이 섞인 로그 acc는 추론 성능과 별개다. 최종은 언제나 디코더 재평가로 판단.
2. **attention은 고빈도에서만 작동** (54.8% ≈ CTC 56.5%), 중·저빈도는 붕괴 (3.2% / 0.4%). 드문 단어는 통째로 오생성 → CER 급증(38.2%).
3. **CTC가 실질 우위** — exact 37.9% vs 30.4%, CER 20.6% vs 38.2%. 중·저빈도에서 CTC가 부분적으로라도 정답을 건짐.
4. **가설 결론**: "데이터가 attention 수렴을 살린다" = 부분 검증 (v2.1 원본 20% → 30.4% 향상). "attention이 CTC보다 좋다" = **기각**.

## 원인 후보 (추가 실험 시)

- attention 디코더가 augmentation noise에 취약 — 증강 이미지가 라벨 순서/불변 패턴을 흐림
- teacher forcing 0.47→0 스케줄이 짧았거나, beam search 구현이 단순 (재정렬/길이 보정 없음)
- 롱테일(1회 등장 64%)은 디코더 방식과 무관하게 데이터 양 문제 — 라벨 정제가 근본 축
